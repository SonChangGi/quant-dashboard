# Capability: public web

Activate when the requested outcome includes a publicly reachable web surface.

- Verify the intended production route, not only a preview or build artifact.
- Read back both HTML and the authoritative data/result identity the browser
  adopts.
- Check cache/version behavior, primary navigation, representative interaction,
  mobile layout, and failure/last-good states.
- Preserve the stable fallback route until the replacement is proven and
  explicitly approved.

Evidence gate: `public_readback`.
