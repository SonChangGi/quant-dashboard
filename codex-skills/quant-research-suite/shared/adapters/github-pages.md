# Adapter: GitHub Pages

- Identify the real source branch/workflow, artifact, base path, custom domain,
  and stable public URL.
- Verify Pages completion after the source change, then read back public HTML
  and the result/data identity consumed by the page.
- Preserve the current Pages route as fallback while a replacement frontend is
  only a preview or parity pilot.
- Account for CDN/cache delay without treating delay as success.
