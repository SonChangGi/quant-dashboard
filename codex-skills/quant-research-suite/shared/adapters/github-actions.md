# Adapter: GitHub Actions

- Inspect the workflow on the active default branch, its event/schedule,
  permissions, concurrency, environment, step IDs, artifacts, and last relevant
  runs.
- Put cost/quota preflight before provider or remote work and make failure
  unconditional and fail closed.
- A dispatch or green job proves only its named steps. Verify result identity,
  publication, deployment, and readback separately.
- Use secrets only through the platform secret channel and never print them.
