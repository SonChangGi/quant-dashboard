# Adapter: Vercel

Vercel is optional preview/hosting infrastructure, not a design or correctness
guarantee.

- Confirm account, team, project, repository/branch, environment variables,
  build command, output directory, plan/quota, and spend hard stops.
- Preview deployment does not replace the stable route until parity, public
  identity, fallback, and user approval are proven.
- Browser bundles receive no server secrets. Treat serverless/backend functions
  as a separately declared backend capability.
- Verify the deployed route and result identity, not only build status.
