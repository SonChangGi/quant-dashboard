# Profile: Quant public dashboard strict

This explicit compatibility profile is for the user's established public Quant
dashboard quality bar. It raises assurance to `strict` and loads the relevant
legacy operating references, but injects no project capability.

Declare repository mutation, web UI, analysis, external data, schedules,
publication, public web, remote release, interactive charts, analysis inputs,
backend, and every adapter only when the project/task actually owns them.

Use it when parity with an existing full dashboard lifecycle is the goal. Do
not use it for a generic website, research-only plan, local prototype, library,
CLI, or a new project whose lifecycle has not been established.

This profile does not permit paid data. Every selected data source and fallback
must satisfy the permanent zero-charge eligibility policy in
`core/authority.md`.
