# Profile: Quant research web

Opt in for a quantitative research page that should follow the user's shared
design grammar. This profile activates `web-ui` and loads the canonical source
resolver at `references/web-design-source.md`.

The design reference is a consistency contract, not a command to clone one
page. Preserve each project's own purpose, analysis, data, results, chart/table
types, and useful identity while aligning navigation, density, typography,
semantic color roles, spacing, states, interaction quality, responsive behavior,
and concise writing.

For analysis inputs or interactive charts, declare those capabilities
separately. The profile must not assume a backend, framework, database, hosting
provider, automated refresh, or release.
