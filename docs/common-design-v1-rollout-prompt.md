# 공통 디자인 v1 프로젝트 적용 프롬프트

아래 프롬프트를 다음 프로젝트의 plan-goal 시작 요청으로 사용한다. 프로젝트 이름·저장소·핵심 차트만 바꾸고 보호 경계와 완료 기준은 유지한다.

## 복사용 프롬프트

```text
[프로젝트 이름]에 Quant Research 공통 디자인 v1.1을 적용해줘.

목표
- 분석 산출물을 바꾸지 않고 결과 우선, 낮은 텍스트 밀도, 충돌 없는 차트를 구현한다.
- 앞서 수정한 프로젝트들과 정보 순서, 조작 방식, 라이트·다크·모바일 품질을 통일한다.

보호 경계
- Python 수집·분석·전략·임계값과 입력값에 따른 기존 결과 변화는 수정하지 않는다.
- 공개 JSON schema·정밀도·날짜 의미·데이터 권리와 workflow·GitHub Pages URL은 수정하지 않는다.
- 프론트엔드는 저장된 결과를 표시하고 탐색만 한다. 보호 경계는 코드·테스트로 증명하고 사용자 화면에서 반복 설명하지 않는다.

문구
- 사용자의 판단이나 다음 행동에 필요 없는 설명은 삭제한다.
- badge·제목·값이 이미 전달한 사실을 문장으로 다시 쓰지 않는다.
- Python, JSON/schema, 재계산 여부, 저장 결과 보존 같은 개발자용 구현 설명은 공개 UI에 노출하지 않는다.
- 신호 없음·중립 상태는 짧은 상태 한 번만 표시한다. 중립 사유와 행별 message/actionExplanation을 카드·표마다 반복하지 않는다.
- 출처·방법론·제한·운영 상세는 필요한 내용만 한 곳의 기본 접힘 영역에 둔다.
- 동일 날짜·동일 대상의 중복 신호는 가능하면 한 visual item에 badge로 합치되 원본 데이터는 변경하지 않는다.

정보 구조
- 결론 또는 최신 핵심값 → 데이터 기준일·핵심 지표 → 핵심 차트 → 필요한 입력·필터 → 표·출처·방법론 순서로 구성한다.
- 정상 상태는 짧은 값으로 표시하고 긴 문장은 warning·error일 때만 사용한다.

차트
- 계열 hover/focus preview와 click/tap/Enter/Space pin을 지원하고 비활성 계열을 흐리게 표시한다.
- 선택일 정확값·단위와 날짜 이동·최신일 복귀·ArrowLeft/ArrowRight/Home/End를 지원한다.
- 정확값 readout은 plot 위에 겹치는 absolute overlay가 아니라 plot 밖의 고정 행에 둔다.
- custom readout이 있으면 SVG native title tooltip과 모든 시점 값 label을 동시에 표시하지 않는다.
- 끝 라벨용 gutter와 collision rule을 두고 선·점·신호·축·라벨끼리 겹치지 않게 한다.
- 모바일 readout은 가로 스크롤 canvas 밖에 유지하고 차트만 내부 스크롤한다.
- 차트 탐색 상태가 분석 입력·공식 결과·URL·저장 설정을 바꾸지 않게 한다.

진행 순서
1. 실제 저장소·공개 화면·데이터 계약과 현재 worktree를 감사한다.
2. 수정 금지 파일과 허용 프론트엔드 범위를 고정한다.
3. visible copy inventory를 만들고 중복·구현 설명·행별 장문을 제거한다.
4. 결과 우선 정보 구조와 차트 충돌 방지안을 구현한다.
5. 기존 계산·데이터 테스트와 신규 UI 회귀 테스트를 실행한다.
6. 데스크톱과 390px 모바일의 라이트·다크를 확인한다.
7. PR·CI·Pages 배포 후 공개 URL을 다시 읽어 검증한다.

검증
- protected diff가 비어 있어야 한다.
- 기존 Python·데이터·정적 계약 테스트가 통과해야 한다.
- 공개 DOM에 중복 설명 0건, 중립 사유 1회 이하, 구현·재계산 설명 0건인지 확인한다.
- active/muted 계열, 날짜 선택, 키보드, 44px touch target, 페이지 overflow를 확인한다.
- readout과 plot·축·직접 라벨의 bounding box가 데스크톱·모바일에서 겹치지 않아야 한다.
- 공개 자산과 최신 main이 일치하고 데이터 기준일·상태가 정상적으로 읽혀야 한다.

완료 보고
- 바뀐 UI와 제거한 반복 문구를 요약한다.
- Python·분석·JSON·workflow 보호 파일이 바뀌지 않았다는 증거를 별도로 적는다.
- 테스트, PR, 배포 실행, 공개 URL을 제공한다.
```

## 적용 원칙

이 프롬프트는 프로젝트별 plan-goal을 위한 시작점이다. 도메인에 없는 신호·날짜·입력을 새로 만들지 않으며, 공통 디자인과 충돌하는 실제 분석 요구는 [공통 디자인 v1](common-design-v1.md)의 허용 예외로 기록한다.
