# 다크모드 기본값 · 2026-10-30

공통 디자인 v0.3.1, 투자일지 v0.8.1. 범위는 공통 메뉴에 연결된 10개 사이트다.

## 동작

- 유효한 URL `theme` → 저장된 사용자 선택 → 기본 `dark` 순서. OS가 라이트여도 첫 방문은 다크다.
- 직접 선택한 라이트 테마와 프로젝트 간 이동 시 선택을 유지한다.
- 새 프로젝트는 시스템 기본값을 사용자 선택으로 저장하지 않는다. 네이티브 초기화 뒤에도 공통 테마 계약을 유지한다.
- 공통 스타일과 테마 부트를 함께 불러오고 셸 생성 전에 다시 적용한다.

## 수정

- Factor 모바일 탐색 표: 넓은 표를 내부 스크롤 영역에 가둬 마지막 열까지 접근 가능하게 수정.
- Fear·ETF: 밝은 파랑 선택/적용 버튼에 어두운 글자 사용.
- DRAM: 다크 차트 5색을 선·끝 라벨·범례·툴팁에 일관되게 보정. 날짜 배지와 비선택 계열 대비 개선.
- SOX: 비선택 산점도 표시, 선택 outline, 축 제목 공간, 빈 결과 정렬 개선.
- DRAM·SOX: 입력·선택 제어 테두리 대비 개선.
- Alpha House: 보조 제어·선택된 작업 메타데이터·프로젝트 이니셜 대비, 오피스 바깥 배경과 스크롤바 개선. 오피스 일러스트와 별도 주간/야간 조명 기능은 유지.
- 투자일지: 종목 검색창과 다음 입력 폼 사이 간격 확보. 네이티브 초기 테마도 dark로 통일.

## 검증 경계

실제 계정의 거래·파일 업로드·계산 실행 자동화는 실행하지 않았다. 투자일지 기능은 명시된 가상 데이터 체험에서 검증하고, 실제 원장은 인증된 읽기 전용 digest/count와 비인증 API 401로 보존을 확인한다. News 생산 파일·발행 런타임·실행 중 자동화는 변경하지 않는다. GitHub 수동 workflow 실행이나 로컬 Python 수집 재실행도 하지 않았다.

상세 JSON과 화면 기록: 로컬 `outputs/quant-dark-review-20261030/{finance,semiconductors,news-journal}`. 공개 배포 산출물에 포함하지 않는다.
