# 공통 디자인 지침 · v0.4.3

## 화면과 조작

- 결과를 먼저 보여준다. AI 특유의 과한 설명·반복·상투적인 제약과 한계 문구는 삭제한다.
- 제목·부제·도움말에서 같은 내용을 반복하지 않는다. 단위·기간·기준·합성 여부는 필요한 위치에 한 번 표시한다.
- 카드의 제목과 숫자는 같은 시작선과 안쪽 여백을 사용한다. 긴 이름은 줄바꿈하고 숫자·단위·결측 표시는 유지한다.
- 차트 값 확인·확대·이동은 직접 조작한다. 상시 모드 버튼과 사용법을 두지 않는다. 확대 후에만 차트 아래에 전체 기간 복원을 표시한다.
- 복원은 확대 범위만 되돌린다. 계열의 색·선택과 비교 기간은 보존한다.
- 비교의 기간·상단 선택·범례·요약·표는 같은 선택 집합을 사용한다. 한 계열은 항상 남기고, 같은 시작일의 양수 관측을100으로 환산한다.
- 마우스로 끌면 구간을 비교한다. 터치에서는 바로 가로로 끌면 관측값을 읽고, 잠시 멈춘 뒤 끌면 구간을 비교한다. 자세한 판정은 아래 조작 계약을 따른다.
- 표는 검색과 데이터가 중심이다. 열·범위·밀도·CSV는 표 도구에서 사용한다. 필터를 적용한 경우 해제를 표시한다.
- 표의 셀 그래프는 전체 자료의 공통 척도를 사용한다. 필터·페이지 변경으로 축이나 순위 의미를 바꾸지 않는다.
- 값의 증가와 개선을 구분하고, %와%p·0과미제공·관측과예측을 구분한다.
- 원자료·정의·구현 JSON은 접어서 제공한다. 오류에는 문제와 해결 동작만 쓴다.
- 키보드 접근과 포커스를 유지한다. 모바일 주요 버튼은44px 이상으로 제공하고 페이지 세로 탐색을 보존한다.

## 배포본에 적용할 때

- 스타일 적용과 기능 적용을 구분한다. 검색·범례·기간·표·CSV를 실제로 조작해 동일한 선택 상태를 사용하는지 확인한다.
- 기간 변경 시 선택은 배열 위치가 아닌 날짜로 유지한다. 해당 날짜가 새 기간에 없으면 선택을 해제한다.
- 검색 결과에도 원래 순위·비중·축 척도를 유지한다. 없는 결과에서 초기화하고 입력으로 돌아갈 수 있어야 한다.
- 지원하지 않는 확대·이동은 안내하거나 지원한다고 기록하지 않는다. 차트 종류는 분석 질문에 필요한 경우에 추가한다.

## 운영 반영

테마 변경 후 실제 계산된 배경·표면·강조색을 확인한다. 토큰 선언만으로 적용됐다고 판단하지 않는다. 긴 카드 이름과 범례 버튼은 데스크톱·모바일에서 함께 확인한다.

변경한 CSS·JS는 내용 해시로 캐시를 갱신한다. 배포 파일과 검증한 빌드의 일치, 공개 화면의 조작 결과를 확인한다. 로컬 탐색 코드·인증 대체 응답·관측 스냅샷은 운영 소스로 옮기지 않는다.

## 실제 화면 적용 기준 · 2026-11-10 보완

- 정보 순서는 제목·단위·간결한 의미색 범례 → 그래프 → 선택 날짜의 상세 값으로 정리한다. 큰 설정 영역이나 선택값 카드가 차트보다 먼저 화면을 차지하지 않게 한다.
- 연결된 패널은 같은 날짜의 실제 픽셀 X 좌표가 같아야 한다. 축 글자 폭에 따라 plot 영역이 달라지지 않도록 공통 좌우 여백을 확보하고, 날짜 눈금은 필요하면 마지막 패널에만 둔다.
- 공통 버튼 스타일은 계열 범례의 의미색을 덮지 않는다. 상태·상승/하락·주제·계열 색은 버튼 안에서도 유지하며, 선택 여부는 테두리·굵기·불투명도로 함께 구분한다.

- 차트는 첫 화면에서 전체 표시 기간과 축을 읽을 수 있게 맞춘다. 고정 폭 차트를 잘라서 가로 스크롤만 제공하는 방식은 모바일 대응 완료로 간주하지 않는다. 시계열의 상세 탐색은 차트 내부 확대·이동으로 처리한다.
- 차트 제목은 카드에 한 번만, 단위는 축 또는 값에 한 번만 표시한다. 범례와 툴팁은 카드 내부에 들어와야 한다. 끝값 라벨을 쓸 때는 공간을 확보하고, 좁은 화면에서는 겹치거나 자르는 대신 툴팁·요약으로 전달한다.
- 시계열은 기본 값 읽기·확대·이동, 확대 후에만 전체 기간 복원, 범례 선택을 제공한다. 수치 비교의 기준·결측·관측/예측 경계·거래 마커는 표현 변경 중에도 유지한다.
- 변경 전에 화면별 보존 목록을 작성한다. 주제·상승/하락·상태·계열의 의미색, 계산·단위·원자료·검색·정렬·CSV·키보드·자동화 연결을 구분한다. 모든 글자를 공통 강조색으로 덮지 않는다.
- 로딩 순서는 테마/저장 설정 → 기본 레이아웃/자리 확보 → 필수 데이터와 핵심 결과 → 부가 시각화다. 데이터가 없을 때 0 또는 정상 상태를 잠깐 표시하지 않는다. 기존 정상 값이 있는 새로고침에서는 값을 보존한다.
- 표의 첫 식별 열, 수치 정렬과 단위, 긴 이름, 결측, 빈 검색 결과를 확인한다. 표는 필요한 경우 내부 가로 탐색을 허용하되 차트의 잘림을 같은 방식으로 정당화하지 않는다.
- 검증은 메인 화면 하나가 아니라 각 차트 유형·주요 탭·빈 상태·반복 조작을 포함한다. 데스크톱과 모바일에서 축·라벨·툴팁·선택 결과를 직접 확인하고, 계산 테스트와 화면 검증 결과를 구분한다.

### 차트 어댑터 회귀 검증

- 정책·레버리지·비용·기간 입력을 바꿀 때마다 그래프·표·체결 원장이 같은 조건과 범위를 사용하는지 확인한다. 선택한 기간의 끝값을 원자료 및 표의 값과 대조한다.
- 기존 렌더러와 새 키보드 핸들러가 한 입력을 중복 처리하지 않게 한다. 방향키 한 번에 관측일 하나만 이동하며, 툴팁·선택 날짜·상세 값이 함께 바뀌는지 연속 입력으로 확인한다.
- 진입·청산·교체 마커는 실제 체결 원장의 상태와 대조한다. 각 상태에 대응하는 색·기호를 유지하고, 렌더러 변경 전후에 거래 날짜와 마커가 일치하는지 확인한다.

## 공통 표면과 직접 조작 · 0.4.3

모든 프로젝트는 초기 HTML에서 [공통 shell.css](https://sonchanggi.github.io/quant-dashboard/shared/design/tokens/0.4.3/shell.css)를 참조한다. 앱 CSS 뒤에 로드하며, 기존 startup 계약이 있는 앱에서는 startup CSS 바로 앞에 둔다. 역할은 `data-quant-card`, `data-quant-card-grid`, `data-quant-section`, `data-quant-metrics`, `data-quant-table`로 연결한다. 프로젝트별 복사본은 공통 파일의 대체 원본으로 편집하지 않는다.

카드는 24px, 모바일 20px 안쪽 여백과 16px 모서리를 사용한다. 카드 간격은 20/16px, 섹션 간격은 32/24px이다. 카드 안에 카드를 겹쳐 감싸지 않는다. 표와 차트는 같은 표면에서 정렬하고, 차트 안쪽 여백은 축과 데이터 가독성에 필요한 만큼만 둔다.

배경과 카드, 읽고 있는 값의 순서에 맞춰 표면을 밝힌다. 본문과 축은 각각 배경에서 읽을 수 있어야 한다. 차트의 격자와 장식 구분선은 숫자보다 덜 두드러지게 한다. 선택·포커스는 청록 또는 하늘색 윤곽으로 표현한다. 상승·하락, 국면, 주제와 벤치마크는 색 외에도 부호·기호·선 모양으로 구분한다.

토스증권의 표·차트·관심 목록은 표면 높이와 숫자 정렬의 참고 사례다. 토스의 컬러 시스템은 명도와 색 역할을 나누는 데 참고했다. TradingView의 직접 조작, Koyfin의 비교 구조, Robinhood의 계열 대비, Stock Analysis의 좁은 화면 구성에서 관찰한 항목을 코드와 예제에 연결한다. [화면별 관찰과 적용 근거](research/APPLIED.md)

## 차트 조작 계약

| 입력 | 결과 |
| --- | --- |
| 짧은 터치 | 손을 뗄 때 한 관측일 표시 |
| 곧바로 가로로 이동 | 날짜를 따라 각 계열의 관측값 표시 |
| 같은 곳에서 약 0.42초 머문 뒤 이동 | 기준점이 표시되고 구간 변화가 갱신됨 |
| 세로 이동 | 페이지 스크롤 |
| 두 손가락 | 손가락 중심 기준 확대·축소 및 이동 |
| 마우스 | 가리켜 값 읽기, 드래그로 비교, 휠 확대·축소, Alt 드래그로 이동 |
| 키보드 | 차트의 방향키·Shift 범위·Escape 해제, 확대 가능한 차트에서 +/−·0 또는 전체 기간 버튼 |

터치 접점이 9 CSS px 이상 움직이기 전에는 드래그를 시작하지 않는다. 이미 값 탐색을 시작한 손가락은 시간이 지나도 비교로 바뀌지 않는다. 오래 누르고 움직이지 않으면 구간이 생기지 않는다. 두 번째 손가락, 스크롤, 중단 이벤트는 진행 중인 비교를 정리한다. 차트 아래의 복원 버튼은 확대 상태에만 둔다. 기간·계열·단위 같은 데이터 선택과 원자료 접근은 별도 위치에 둔다.

비교는 날짜·시작값·끝값·변화량을 보여준다. 양수 가격은 %, 수익률·확률 수준은 %p, 점수는 절대 차이를 사용한다. 시작값이 0 이하이면 절대 차이와 변화율 —를 표시한다. 결측값을 보간하지 않는다. 역방향 드래그는 시간순으로 정규화한다. 카테고리 차트와 산점도는 구간 합계·대상 수 등 각 차트의 의미로 해석한다.

모바일 검증은 터치 시작만 한 상태, 미세 이동, 연속 탐색, 길게 누른 뒤 역방향 비교, 두 손가락 전환, 세로 스크롤을 각각 확인한다. 320px와 390px에서 숫자, 범례, 차트 아래의 결과를 읽을 수 있는지 확인한다. 1440px에서 휠·키보드·테마를 점검한다. 브라우저 터치 에뮬레이션과 실제 기기 조작을 구분해 기록한다.

## v0.4.4 · 구간 결과, 비교 축과 기사 상단

- 시간 구간의 두 끝을 표시하고, 선택 중에는 한 시점의 툴팁을 감춘다. 변화량은 공간이 충분한 플롯 모서리에 배치한다. 구간과 값 사이의 시선 이동을 줄이고 끝점·축 눈금·손가락 위치가 가려지지 않는 쪽을 우선한다.
- 좁은 화면은 두 계열, 넓은 화면은 세 계열까지 플롯 안에서 읽을 수 있는지 먼저 확인한다. 실제 픽셀과 텍스트 높이가 기준이다. 더 많거나 여러 패널에 걸치면 바로 아래에 날짜, 계열, 증감 값, 양 끝 관측을 정렬한다. 화면 하단에 띄우지 않는다. 확대·범례 변경·가로 폭이 바뀌어도 구간과 값은 같이 움직인다.
- 가격은 시작값이 양수일 때 상대 변화율, 이미 %로 표현된 누적 수익률·확률·편입 비중은 %p 차이를 쓴다. 0 이하에서 상대 변화율을 계산하지 않는다. 결측은 대시와 관측 없음으로 구분한다. 영역 선택은 종목 수와 축 범위, 순위 막대 선택은 합계나 범위를 기존 의미대로 표시한다.
- 같은 측정값을 옆에서 비교하는 축은 0을 유지하고 현재 표시 대상의 실제 최댓값을 조금 넘는 눈금으로 맞춘다. Top 5와 Top 10 혼용 시 세 카드의 축을 함께 갱신한다. 사분면에는 기준선을 표시하고 상위와 선택된 종목을 한 번에 구분한다. 라벨은 채운 글자와 위치 조정으로 읽히게 하고, 모든 점을 이름으로 덮지 않는다.
- News는 주제 태그의 의미색을 유지하면서 출처·시각·저장을 한 묶음으로 배치한다. 링크와 저장 상태는 원래 노드를 사용한다. 한 줄에 안 들어가면 출처와 저장이 같이 다음 줄로 이동한다.
